# 000129 — a gesture did not reach intake
**Historical checked evidence:** September 2026. During a real human trial of
a small authorized edit, the preserved diagnosis says a double-click gesture
did not reach the stop receiver. No corresponding intake/settlement was
identified. The isolated edit ran and its validation failed; that failure is
not a successful stop.

**Limit:** the precise gesture timestamp is not recoverable from an intake
record. The later diagnosis and the attempt record have different roles.

**Interpretation:** an apparent human gesture is not evidence of receipt.

**Derived example:** [E01](../../examples/01_signal_not_received/README.md) uses a
wrong target deterministically. It does not recreate the historical UI defect.
**New tests:** wrong-target and instance-isolation checks belong to STOPPER.
