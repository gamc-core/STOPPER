# 000144–147 — presentation and execution diverged
**Historical checked evidence:** 28 September 2026. The preserved closure
documents six conversational stops across four sessions. They reached
TOO_LATE / DISPATCH_STARTED: the provider calls had begun, and no call was
recorded as prevented. Early trials delivered an unsatisfactory late response.
Later records mark local presentation suppressed while retaining the response
in history. Human acceptance of that experience is recorded separately.

**Limit:** these records do not prove remote cancellation, stopped billing,
token interruption or what happened inside the provider.

**Interpretation:** a satisfactory interaction can coexist with completed
underlying work. Suppression must not be sold as cancellation.

**Derived example:** [E04](../../examples/04_presentation_is_not_execution/README.md)
uses one local synthetic operation, records NO_EFFECT and suppresses delivery.
Its separate TOO_LATE receipt is a new local example, not the historical event.
