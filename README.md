# STOPPER
*Cooperative stopping and observable outcomes*

**Private construction in progress. Publication is not authorized.**

You asked it to stop. What actually stopped?

STOPPER is being built for people writing local, cooperative batch operations:
a stop request should be distinguishable from the worker noticing it, and from
the work that actually remains.

The initial [contract](docs/CONTRACT.md) fixes the scope before implementation.
The [decisions](docs/DECISIONS.md) record real development, including failures.
Executable examples and reproduction instructions will be added as they exist.

Derived from experiences in Arquitectura Simbiotica / DOJO; this repository
imports neither its runtime nor its private Git history.
